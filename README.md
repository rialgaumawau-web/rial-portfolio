# rial-portfolio

Overview
This project is my personal portfolio website for the course. It includes four pages: Home, About Me, Projects, and Contact. The site is built using HTML and CSS only, with responsive design through media queries and separate CSS files for each viewport.

Responsive Design
I used fluid design and media queries to make the site work on mobile, tablet, and laptop screens.
The breakpoints I used are:

Mobile: max‑width: 480px

Tablet: 481px to 960px

Laptop/Desktop: min‑width: 960px

These dimensions match the ranges we used in class and cover the most common device sizes.
Each viewport has its own CSS file: mobile.css, tablet.css, and desktop.css.

I avoided flexbox completely since it’s not allowed for this assignment.

Color Scheme
I created my color palette using Adobe Color.
The scheme I chose is a monochromatic dark theme with gold accents.
My main colors:

Dark gray / black for backgrounds

Gold (#D4AF37) for headings and highlights

White for text

Medium gray for secondary elements

I picked this scheme because it looks clean and matches the style I wanted for the portfolio.

Gradients Used
I used both a linear gradient and an angled linear gradient in the site.

The header/banner uses a horizontal linear gradient.

The footer uses a 45‑degree angled gradient.

I added these in the desktop CSS file.

Testing & Validation
I validated and tested the site using the required tools:

HTML Validation: W3C Markup Validator

CSS Validation: W3C CSS Validator

Link Checker: W3C Link Checker

Spell Check: Used an online spell checker

Accessibility: Tested with WAVE

I fixed any errors that showed up during validation.
